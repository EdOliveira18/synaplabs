# Zimmari Móveis Planejados

Site institucional de página única. Referência em planejados na Região dos Lagos, RJ.

## Estrutura

- `index.html` — página completa, com CSS e JS inline
- `*.webp` — fotos dos projetos entregues e as duas versões do logotipo
- `favicon.png` — ícone da aba
- `vercel.json` — cache dos assets e clean URLs

## Deploy

Hospedado no Vercel, projeto `zimmari-planejados`. Todo push na branch `main` publica em produção.

Domínio: zimmariplanejados.com.br
